# Nilinde brand palette

Three core colours sampled from the current pitch deck:

| Name | Hex | Use |
| --- | --- | --- |
| Nilinde Violet | `#5D40A4` | Primary brand colour, headings, and primary actions |
| Warm Peach | `#EDB390` | Accent colour and highlights |
| Cloud White | `#F8FAFD` | Light backgrounds and contrast |

The updated mother-and-child logo uses Nilinde Violet as its background, Cloud White for the mother silhouette, and Warm Peach for the child silhouette.
