# kuuma_ui

Flutter: `KuumaTheme`, `KuumaButton` / `KuumaCard` / `SeverityBadge` / `EmptyState`, `KuumaL10n` (en, lg, nyn, sw, with prefix rule and English fallback), `LockScreen` (PIN + fingerprint), `QuickHide` / `DecoyScreen` / `NeutralNotification` (discreet mode), and `SlotRegistry` / `KuumaFlutterModule` (navigation slots: `child.tab`, `child.settings`, `parent.tab`).

Brand colors are documented in the root design system. The updated launcher artwork is at `assets/branding/kuuma-icon.png`.
