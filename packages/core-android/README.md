# kuuma-core-android

Kotlin library (API 21+): `bus/` (EventBus, ModulePublisher, CloudGate), `storage/` (SQLCipher per module, Keystore-wrapped keys), `crypto/` (SHA-256, OpaqueRefs, DeviceSigner with Keystore → legacy → software fallback, recorded as `KeyProtection`), `redact/` (BasicRedactor), `permissions/` (PermissionRegistry), `log/` (SafeLog), `module/` (KuumaModule, ModuleRegistry). Lint checks in `../core-android-lint` ship with it.
